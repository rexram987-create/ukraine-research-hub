# Ukraine Research Hub — מרכז מחקר אוקראינה

אתר סטטי בסגנון אתר פולין, מוכן ל־GitHub Pages.

## קבצים מרכזיים

- `index.html` — שער צבעוני ראשי
- `ukraine.html` — דף מחקר מדינה
- `timeline.html` — ציר זמן
- `jewish-ukraine.html` — יהדות אוקראינה
- `sources.html` — מקורות וקרדיטים
- `about.html` — אודות
- `cities/` — דפי ערים
- `assets/css/site.css` — עיצוב כללי וניווט
- `assets/js/dropdown-nav.js` — ניווט נפתח
- `assets/images/README-images.txt` — שמות תמונות מומלצים
